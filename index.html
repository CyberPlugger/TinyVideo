TinyVideo

A local-first AI video generation system built from the ground up in Python. Experiment, train, generate, and control the entire pipeline locally.

Download TinyVideo View on GitHub
Capabilities

Small system. Big ambitions.

TinyVideo is designed as a modular AI video generation project where every part of the pipeline can be inspected and improved.

🎬

Text-to-Video

Generate short videos from natural-language prompts using a diffusion-based video model.

🖼️

Image Conditioning

Use an input image together with a prompt to influence the generated video.

🧠

Latent Diffusion

Perform the diffusion process in a compact latent video representation.

📐

Resolution Conditioning

Resolution can be treated as a controllable property of the generation pipeline.

🏋️

Local Training

Create datasets and train the TinyVideo model locally.

🖥️

Local GUI

Access generation, image generation, dataset tools, and training through a Tkinter interface.

Architecture

Built as a pipeline.

TinyVideo separates prompting, conditioning, diffusion, decoding, and video output.

User Prompt
→
Text Encoder
→
Conditioning
→
Diffusion
→
Decoder
→
Video

Image-conditioned generation adds an image encoder alongside the text-conditioning path, allowing visual information to influence the generated video.

Local First

Roadmap

This is only the beginning.

TinyVideo is being developed continuously.

Current

V1.4

Latent diffusion, text conditioning, image conditioning, dataset conversion, local training, and the first local GUI.

Planned

V1.4 Pro

Increase the model's working dimensions while maintaining a square video format, with the goal of improving visual quality and generation capability.

Planned

TinyAudio

A separate local audio-generation system designed to eventually generate audio from the same user prompt.

Long Term

Video + Audio

TinyVideo and TinyAudio independently generate their outputs before being combined into a final video.
