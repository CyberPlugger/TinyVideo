# TinyVideo AI

Python 3.13.5

My own first ever AI video generator working on a local server.

## Minimum Specifications and requirements:
* 12GB RAM 
* 128MB display storage 
* UHD Screen
* 128GB Storage

# DO THIS BEFORE ACTIVATING THE PROGRAM!
Change the python interpreter to `...\TinyVideo\.venv\Scripts\python.exe`, or else the program will crash

Have 64 bit python interpreter or else torch will not launch

`.venv` folder is not in the project but in the releases, they are gonna be uploaded soon.
